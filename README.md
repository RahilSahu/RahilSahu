## My open-source security tools

Small, zero-dependency Python tools I built for assessment work and
learning. Each one is a single readable file with offline unit tests.

- [http-security-headers-checker](https://github.com/RahilSahu/http-security-headers-checker):
  checks a site for missing or weak HTTP security headers and scores it
- [tls-cert-inspector](https://github.com/RahilSahu/tls-cert-inspector):
  inspects TLS certificates for expiry, self-signing, hostname and
  protocol problems
- [dns-email-auth-checker](https://github.com/RahilSahu/dns-email-auth-checker):
  checks SPF, DMARC, DKIM and CAA records so a domain cannot be spoofed
  easily
- [port-scanner-lite](https://github.com/RahilSahu/port-scanner-lite):
  a careful TCP connect scanner with banner grabbing and notes on risky
  exposed services
